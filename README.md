# Database-Management
Public repository for CSCE 45203 Database Management Systems at the University of Arkansas.

## Project 1
Database system implemented using a sorted file of fixed length records and simple command line interface programmed with Python.

To run, execute `python3 TestDB.py`.

## Project 2
Database system similar to Project 1 except it's implemented with MySQL.

To run, execute `python3 main.py`. A MySQL database is required; replace the database credentials in `main.py`.
